## 怎么维护

按发生的变化更新对应信息，不要求每次修改所有文档：

| 变化 | 更新位置 |
| --- | --- |
| 新需求、缺陷、后续建议 | 待办与路线图；涉及平衡或原画时链接专题记录 |
| 任务开始、实现完成、验证结果变化 | 待办状态 + 项目状态中的对应条目 |
| 确认或改变重要设计选择 | 决策记录 + 对应产品规格／风格指南 |
| 自动范围或玩家操作改变 | Beta 说明 + 产品规格 |
| 卡牌、规则或技能接口改变 | 按 AGENTS.md 和技能引擎约定同步专题文档 |
| 发布完成或回滚 | 发布清单逐项核验，再更新项目状态中的发布证据 |

需求确认由项目负责人决定，实施者随变更维护记录；真机／实战由实际执行者记录结果。不要虚构负责人、完成日期或发布结果。未确认的建议标明“建议”，发现旧记录失实时标明原因并修正当前摘要，历史验收记录保留当时的范围。

这里的状态和待办只描述事实与安排，不授权提交、推送或部署，也不设置自动定时维护。
