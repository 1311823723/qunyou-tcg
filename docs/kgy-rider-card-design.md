# KGY：巡界流与骑士卡设计确认稿

状态：KGY 本体双面与六种骑士卡均已写入正式数据，规则引擎和牌桌六槽已经实现。巡界预组尚未建立，因此 KGY 暂不向玩家开放。

## 本轮范围

- 群友名确定为 KGY，原型方向为《假面骑士 Decade / 帝骑》。
- 本体原画已归档并合成双面设计卡，骑士卡暂用统一定位色槽，不制作新原画。
- 本体正式数据以 `data/cards/bodies.json` 为准，骑士卡正式数据以 `data/cards/rider_cards.json` 为准。
- 本轮不修改既有角色数量、现有九套预组或自动对战玩家可选范围。

## 设计目标

核心循环：对手角色技能结算 → 记录尚未持有的定位力量 → 消耗骑士卡应变 → 累计四次驾驭 → 极巨化获得全部六种FINAL → 不补充、择机消耗 → 极巨化结束后剩余卡恢复普通版。

六种骑士卡只提供固定效果，不复制角色技能文本。这样可以体现“你展示过的力量，我也能驾驭”，又不随新角色增加而不断扩大复制范围。

与现有本体区分：Joker 通过己方不同定位连携调度角色；摆子通过转化与虚拟牌补位；小阿潘围绕伏击费用补位；KGY 依赖对手展示的定位收集公开资源，走反应型工具箱方向。

## 本体确认稿

### 正面

- 名称：KGY
- 卡牌类型：本体，体力 7
- 称号建议：巡界旅者
- 所属预组：巡界组（暂名，尚未建立正式预组）
- 机制定位：巡界流，观察、资源储备、反制与择机爆发
- 标签建议：骑士卡、应变（设计标签，暂不新增正式标签表）
- 费用：特性获得骑士卡无费用；使用骑士卡消耗该卡，并退场己方角色区内1张相同主定位角色
- 时机：对手的一张角色技能结算后
- 特性名建议：世界巡游
- 英文装饰文字：KAMEN RIDE

卡面文本草案：

> 每回合限一次，当对手的一张角色技能结算后，若你未持有与其主定位对应的骑士卡，你可以获得该骑士卡。每种骑士卡至多持有1张。每回合至多使用1张普通骑士卡，使用时消耗该卡，并将己方角色区内1张相同主定位的角色退场。

极巨化条件：

> 累计使用4张普通骑士卡后，极巨化就绪。

设计说明：次数只在成功获得骑士卡时消耗。已持有该定位、未满足条件或主动放弃，均不消耗本回合的获取机会。这里保留“可以”，因为提前选择一种定位会占用本回合唯一获取机会，不能默认自动拿取。

平衡风险：普通形态不保证直接摸牌，收益受对方定位和发动频率影响。以“使用次数”变身减轻了收集六种不同定位的压力，但没有消除对局组合差异。

### 极巨化面

- 名称建议：极巨巡界者-KGY
- 卡牌类型：极巨化本体
- 所属预组：巡界组（暂名）
- 定位：有限次数的强化应变
- 标签建议：骑士卡、极巨化
- 费用：进入极巨化时获得卡不消耗能量；使用FINAL骑士卡须消耗该卡及1点极巨能量，并退场己方角色区内1张相同主定位角色
- 时机：进入极巨化时获得全部FINAL；各卡按自身时机使用；结束极巨化时将剩余卡恢复普通版
- 极巨技能名建议：终极驾驭
- 英文装饰文字：FINAL RIDE / COMPLETE FORM

卡面文本草案：

> 进入极巨化时，获得全部六种FINAL骑士卡各1张（替换已有普通卡）。每回合至多使用1张，使用时消耗该卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场。极巨化结束时，将剩余FINAL骑士卡变回普通卡。

卡面省略“不补充”句子以精简展示；极巨化期间不记录、不补充骑士卡的规则不变，已同步到规则与关键词文档。

本版调整（2026-09-03）：进入极巨化时一次获得六种FINAL各1张，替换已有普通卡，不叠加两套。此后整个极巨化期间禁止获得或补充骑士卡，不再记录对手的新定位。

极巨化期间正面特性暂停，背面也不提供获取触发。使用后的卡不返还；极巨化结束仅将仍持有的FINAL变回普通卡，不恢复已消耗的卡。正面特性恢复后，才能按正常流程重新获得缺少的普通卡。

例如：变身后持有六种FINAL。先后使用强攻、防御、资源各1张并耗尽3点能量，结算完毕后恢复本体，留下普通控制、支援、伏击各1张。已消耗的三种不会随变回普通形态而补回。

设计说明：沿用当前极巨化的准备阶段变身、每局一次、3点能量和2点极巨体力。极巨体力不是体力上限加2。能量仅在使用骑士卡时消耗；这是KGY专属的费用分配，不额外叠加一次能量费用。最后一张耗能卡结算完毕后才结束极巨化，不在回合末扣能量。规则引擎已按此专属费用实现。

平衡风险：变身不再依赖原有储备即可解锁全部六种强化选项，稳定性更高；3点能量通常只能选用其中三种，且每种在极巨化期间最多消耗一次。每回合最多使用1张，三次使用分布在至少三个玩家回合内，并非必须三个己方回合。剩余卡降级保留提供后续收益；不耗能时可长期保留FINAL但不能持续积累，需要试玩评估。

## 骑士辅助卡确认稿

共同属性：本体专属公开资源，不是手牌或角色牌；每种至多持有1张，普通与FINAL共用此上限。它们不占角色位，不进入共用牌堆或手牌弃牌区，也不受普通手牌效果影响。六张辅助卡不计入54张手牌、16张角色预组或120张角色总量。

制卡建议：每种一张双面辅助卡，正面普通、背面FINAL。六张卡对应六种主定位，但不是新增六张角色。下列名称兼作技能名，各归属巡界组专属组件。

费用阅读规则：普通形态使用普通卡，消耗此卡；极巨化期间仅持有并使用FINAL，消耗此卡及1点能量。两种版本都须将己方角色区内1张与骑士卡相同主定位的角色退场。不能无卡或无对应角色发动；退场属于费用，不会发动该角色技能，也不产生休整摸牌奖励。两种版本共用每回合至多使用1张的上限，变身或恢复普通形态不重置本回合使用次数。进入极巨化获得全部FINAL不消耗能量、角色或使用次数。

### 1. 强攻骑士卡 / ATTACK RIDE

- 定位、标签：强攻；强化
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：当你使用【出刀】时
- 普通效果：令此【出刀】造成的伤害+1。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：你的出牌阶段
- FINAL效果：视为对对手使用1张【出刀】。此【出刀】不计入本回合使用次数，且造成的伤害+1。
- 设计说明：从强化现有攻击升级为额外攻击，仍允许正常响应。
- 平衡风险：额外出刀与其他增伤叠加可能产生爆发；不能将其实现为不可响应的直接伤害。

### 2. 防御骑士卡 / GUARD RIDE

- 定位、标签：防御；减伤
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：当你将受到伤害时
- 普通效果：令此次伤害-1。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：当你将受到伤害时
- FINAL效果：防止此次伤害。
- 设计说明：均在伤害落实前处理，不防止失去体力。
- 平衡风险：FINAL可以抵挡高额伤害，与2点极巨体力叠加的生存收益较高。

### 3. 资源骑士卡 / RESOURCE RIDE

- 定位、标签：资源；摸牌
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：你的出牌阶段
- 普通效果：摸2张手牌。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：你的出牌阶段
- FINAL效果：摸4张手牌，然后弃置1张手牌。
- 设计说明：支付资源角色退场费用后，普通版获得2张手牌，强化版净增3张并筛选手牌；两者均牺牲角色储备。
- 平衡风险：普通形态获得资源骑士卡依赖对方使用资源角色；极巨化时可稳定取得FINAL资源，收益须与其他FINAL的耗能机会比较。

### 4. 控制骑士卡 / CONTROL RIDE

- 定位、标签：控制；角色控制
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：你的出牌阶段
- 普通效果：将对手角色区内1张明置角色置于其角色牌堆底。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：你的出牌阶段
- FINAL效果：将对手角色区内1张明置角色退场。
- 设计说明：普通版置底不视为休整，不洗牌；FINAL改为退场。两版均限制明置目标，不处理暗置角色。
- 平衡风险：用己方控制角色退场交换对方已知威胁；普通版对手仍可重新抽到，FINAL移除更彻底，但另需能量。对方无明置角色时不可使用。

### 5. 支援骑士卡 / SUPPORT RIDE

- 定位、标签：支援；布阵
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：你的出牌阶段
- 普通效果：从角色牌堆顶暗置上阵至多2张角色，角色区仍不能超过4张。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：你的出牌阶段
- FINAL效果：选择己方退场区内1至2张角色，将其洗回角色牌堆。
- 设计说明：普通版发动前角色牌堆至少有1张牌；费用角色先退场，因此其腾出的角色位可用于此次上阵。FINAL 可以选择刚作为费用退场的支援角色，不继承普通版的上阵效果。
- 平衡风险：普通版可在原有空位较多时快速补场，满场时实际只补回费用腾出的1个位置；FINAL以场面换长期角色资源，需要与资源骑士卡竞争极巨能量。

### 6. 伏击骑士卡 / AMBUSH RIDE

- 定位、标签：伏击；反制
- 普通费用：消耗此骑士卡，并将己方角色区内1张相同主定位的角色退场
- 普通时机：对手的一张角色技能结算后
- 普通效果：若发动该技能的角色仍在其角色区，将其洗回角色牌堆。
- FINAL费用：消耗此骑士卡及1点极巨能量，并将己方角色区内1张相同主定位的角色退场
- FINAL时机：对手发动角色技能并支付费用后、该技能效果结算前
- FINAL效果：令此次角色技能失效。已支付的费用不返还。
- 设计说明：普通版先让效果生效再处理发动者；FINAL让对手支付费用但抵消效果。休整自身或退场自身可使发动者自然避开普通版。
- 平衡风险：FINAL反制退场技能价值很高。技能失效不会撤销费用，费用产生的角色移动保持有效。

## 预组方向与现有联动

建议巡界组采用应变中速方向，不围绕自己凑齐六定位发动特性，因为获得骑士卡读取的是对手角色。

- 基础牌检索与攻击补给配合强攻骑士卡，避免拿到增伤却没有【出刀】。
- 使用骑士卡必须有对应主定位的在场角色，构筑需要兼顾六定位覆盖与退场后的续航；支援卡可以用补位和退场区回收维持角色循环。
- 防御、回复角色帮助KGY度过积累四次使用的前期。
- 情报角色帮助判断明置目标的移除价值，以及何时保留FINAL伏击。
- 参考对照：微笑尅乐稳定强化出刀，瓜猫稳定获得行动牌收益，KGY用稳定性换工具数量；不宜再附赠无条件摸牌。
- 本轮不确定16张列表，不新建角色，不更改任何现有预组。确认核心机制后优先复用已有角色，再检查缺口。

## 制卡与原画安排

建议第一批制作双面本体，第二批制作六张双面骑士辅助卡；十二种效果不全部塞进本体文本区。

1. 本体正面：KGY的鹅形角色，帝骑常态装甲、驱动器与抽卡动作；品红、黑、白为建议主配色。鹅身颜色、脸部特征和比例需先确认，不直接套人类盔甲身材。
2. 极巨化面：保持同一鹅形角色，Complete Form方向装束；前景人物足够大，巨大灵体或巨型投影放在身后表现极巨化，不挤占主体。头脸与关键手势留在卡面文字框以上。
3. 六张辅助卡：统一轮廓与身份符号，以六种角色定位的项目既有配色区分，FINAL增加一致的强化识别。具体色值制卡前读取现有渲染器，不另造一套冲突色表。
4. 原画不生成文字、数值、水印或现成卡框；英文唱名、中文技能与边框由制卡层叠加。帝骑装甲自身的卡片装饰属于角色造型，不等于绘制整张游戏卡框。
5. 绘图前查证帝骑常态和Complete Form造型并读取现有本体原画参考。本轮不声称已经核实附件中的英文形态名称，暂用它作方向备注，不印成长标题。
6. 候选原画放 `/private/tmp/qunyou-character-art/body_roaming_001/`，其中ID仅为拟用，正式写入前检查唯一性。
7. 用户确认原画后，才按制卡工作流归档至 `src/assets/card-art-source/bodies/`；建议slug为 `kgy-body` 与 `kgy-body-dynamax`。确认接入后再串行注册。
8. 骑士辅助卡尚无正式schema或导出模板。设计确认阶段可以做独立排版预览，不能伪装成手牌写进54张手牌牌堆。

## 需要确认的边界

- 极巨化结束时剩余骑士卡（已确认）：仍持有的FINAL全部变回普通卡，已消耗的卡不补回。
- 极巨化使用次数（最新确认）：普通与FINAL共用每回合至多1张的限制，每次消耗对应卡及1点能量。同一触发事件不能重复发动，不因升级或重新获得卡而重置使用次数。
- 同类型重复使用：普通形态允许跨回合重新获得后再次使用，不增加每种每局一次限制。极巨化期间每种只有1张且不能补充，因此消耗后无法再次使用该类型。
- 普通形态同一事件获得并使用骑士卡（已确认）：新获得的骑士卡不能用于产生该卡的同一次技能事件，下一个符合时机的事件才可使用。
- FINAL强攻、资源、控制与支援固定限定在自己的出牌阶段。
- 技能失效与复制定位（已确认）：已经支付费用并走完结算流程的技能仍能触发获取；复制技能按实际发动角色的 `mainRole` 收集。
- 制作辅助卡的实体持有状态表达：建议用持有区/未持有区，不用正反面表示0/1，因为正反面已承载普通/FINAL文本。

## 执行顺序

1. 确认机制边界、本体称号和双面辅助卡方案。
2. 确认KGY鹅形外观，生成两面本体候选原画。
3. 确认原画，再写正式卡牌数据、机制规则及变更日志，生成整卡；辅助卡另做专用模板。
4. 试玩评估并确定巡界组16张角色，通过真实对局验收后开放 KGY。

当前正式数据位于 `data/cards/bodies.json` 与 `data/cards/rider_cards.json`。后续只需确定巡界组16张角色、补充真实对局测试，再决定是否制作独立骑士卡原画与实体辅助卡。
