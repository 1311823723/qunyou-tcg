# 钛晶化本体设计草案

更新日期：**2026-09-10**。本文记录四张钛晶化本体的共同设计边界；具体本体名称、技能文本、钛晶化条件和 PET 数值尚未定稿。

## 设计定位

钛晶化是本体卡自带的额外形态。它不是一个独立的通用按钮，也不是所有本体都能使用的公共系统。

- 只有明确写有钛晶化形态的本体，才拥有钛晶化条件和背面。
- 本体正面提供稳定、保守、偏被动的流派发动机，主要影响预组的大方向。
- 本体不是预组的操作核心；角色牌、手牌和角色技能仍然承担主要操作量。
- 背面是同一角色的强化动作与构图，不更换角色身份，只表示进入强化状态。
- 背面效果由“本体强化特性 + 玩家选择的一张 PET”组成。

## 形态与选择规则

1. 每张钛晶化本体都有自己的正面特性和独立钛晶化条件。
2. 满足条件后，玩家在规定时机确认是否钛晶化；拒绝时保留已满足的状态，直到下次合法询问。
3. 确认钛晶化后，本体翻到自己的背面，并从六种 PET 属性中选择一种覆盖。
4. PET 每局只能选择一次。覆盖完成后不能更换、移除或重新选择。
5. PET 效果从覆盖完成后开始生效，不追溯钛晶化前的事件，也不能重复触发同一事件。
6. 本体背面、PET 和其他技能分别记录触发与次数；PET 不改变角色牌的 `mainRole`。

钛晶化、Mega、Z 招式和极巨化均由本体卡自己声明。除非某张本体卡另有明确文字，同一局不允许再把本体切换到另一种额外形态，避免多形态叠加造成结算顺序和组合数量失控。

## 六种 PET 的职责边界

PET 是跨本体复用的轻量被动修正，不应单独组成一套操作系统。六种属性先固定设计领域，最终触发条件和数值在逐张本体试配后确定：

| PET 属性 | 主要负责 | 不应承担 |
| --- | --- | --- |
| 强攻钛晶 | 【出刀】、造成伤害及伤害后的收益 | 连续出刀引擎、独立大招 |
| 防御钛晶 | 成为目标、受到伤害、成功防守 | 无限抵消或完整濒死替代 |
| 资源钛晶 | 摸牌、手牌交换、牌堆质量 | 大量检索或无限循环 |
| 控制钛晶 | 查看、展示、限制对手选择或牌的使用 | 永久封锁对手整套角色 |
| 支援钛晶 | 己方角色技能、费用和角色区操作 | 代替角色牌连续上阵 |
| 伏击钛晶 | 对手回合、响应窗口和对手技能事件 | 取代所有响应牌 |

PET 的正式文字应尽量是一条短被动，通常只改一个事件或一个结果。不能因为 PET 选择而新增复杂的多步主动流程。

## 本体技能约束

- 正面特性和背面强化特性优先采用自动触发的被动效果。
- 每张本体最多保留一个需要玩家主动按下的效果；若存在，该效果应短、明确且不成为预组的主要操作核心。
- 不把摸牌、换牌、选择角色、调整牌堆等所有资源操作集中到本体上；这些职责应分散给角色牌。
- 钛晶化条件应围绕本体自己的被动循环累计，玩家能通过正常玩预组自然接近条件，而不是被迫重复同一按钮。
- 六种 PET 套入同一张本体后都应存在合理选择，不能出现一眼就能淘汰五种属性的固定答案。

## 新角色牌配套原则

后续角色池计划从 120 张扩展到 160 张。四张新钛晶本体预计各自贡献约 10 张新角色，但每个预组仍应混用现有角色：

- 5～6 张核心角色：直接回应该本体的钛晶化条件或背面特性。
- 2～3 张桥接角色：把钛晶机制与现有手牌、角色区或定位机制连接起来。
- 1～2 张通用角色：补足费用、定位和防守曲线。
- 其余位置优先复用已有角色，不为填满 16 张而重复造卡。

新角色围绕机制标签设计，而不是写死只能与某一张本体配合。新增角色必须先证明现有角色无法表达该机制，且至少有三张角色能够形成互动，再进入正式数据。

## 开发顺序

1. 先为四张本体各写出正面特性、钛晶化条件和背面强化特性的草案。
2. 用六种 PET 逐一套入第一张本体，淘汰明显无效或过强的 PET 文案。
3. 固定 PET 的短被动模板，再设计其余三张本体。
4. 为每张本体补充核心角色和桥接角色，最后用旧角色完成预组。
5. 在具体技能定稿前，不新增自动化处理器、卡面文本或正式卡牌数据。
