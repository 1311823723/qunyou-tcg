# 自动对战 Beta

自动对战 Beta 与经典手动对战共用大厅、昵称、房间码、重连和观战入口，但使用独立的牌桌页面与 Durable Object。自动版出现问题时，不会改变经典房的状态或操作方式。

彻底自动结算的产品目标、发布门槛和阶段见 [`auto-battle-product.md`](auto-battle-product.md)；技能注册、事件、可持久化选择与测试规范见 [`auto-battle-skill-engine.md`](auto-battle-skill-engine.md)。

## 当前自动范围

- 自动开局：双方摸 5 张手牌、暗置上阵 2 张角色，并随机决定先手。
- 六阶段循环：准备、摸牌、出牌、布阵、弃牌、结束。
- 摸牌阶段自动摸 2 张；布阵阶段至多上阵 2 张角色，角色区最多 4 张。
- 弃牌阶段按 `min(当前体力, 4) + min(己方明置角色数, 2)` 自动检查上限。
- 54 张实体手牌的目标、响应、牌区移动、伤害、回复与阶段效果。
- 响应栈、【闪避】、【别急】、【紧急会议】、小王转化和濒死【急救】。
- 牌堆不足时将共用弃牌区洗回牌堆。
- 胜负判断、公开日志、断线重连和观战隐私。
- 8 张本体的正面技能、Mega 强化与 Z 招式：系统自动记录进度、翻面、次数、费用修正和每局限一次状态。
- 操作组与上头组共 32 张角色的触发、费用、目标、分支、牌堆移动、充能球、伤害替换、延迟炸弹和技能复制全自动结算。

自动版不设置倒计时。存在响应、选择、濒死或未完成结算时，当前玩家不能推进阶段。

## 本体技能自动结算

八个流派本体已使用结构化事件自动结算，不从卡面中文临时解析效果。自动范围包括：

- 爆杀流的伤害进度、额外【出刀】次数和 Mega 结束阶段【出刀】。
- 密裁的有效观看计数、展示手牌、选择弃置和 Mega 摸牌。
- 行动流的行动牌计数、伤害检查和 Mega 牌堆顶选牌。
- 拟态流的虚拟牌触发、暗置补位、结束阶段休整和 Mega 费用减免。
- 调度流的明置计数、牌堆顶整理、对手明置换牌和 Z 招式换阵。
- 卖血流的受伤判定、红黑分支、随机弃牌和 Z 招式弃牌区回收。
- 伏击流的离场补位，以及 Z 招式对退场伏击角色的限时免费发动。
- 防御流的抵消/防止/减伤计数、摸牌观看，以及 Z 招式致命伤害防止。

需要玩家发动的可选本体技能会进入私有选择窗口；对手和观战者只会看到等待状态和最终公开结果。

上头、密裁和操作三张本体已迁移为 `worker/src/skills/bodies/` 下的独立技能模块；变通、执棋、逆命、幽幕和不落仍保持完整自动结算，但暂时通过兼容层运行。

## 角色技能与预组解锁

角色技能不从中文效果文本推断规则。`data/cards/character_automation.json` 为 120 张角色登记机器可读的触发时机、次数限制和可用原子操作；技能费用仍读取角色牌 JSON 中的结构化 `cost`。

系统负责验证时机、明置发动者、支付休整或退场费用、处理休整摸牌、记录次数并写入公开日志。操作组与上头组使用稳定 ID 的独立角色模块，多步选择保存为 `SkillContinuation`，断线后可从同一步骤继续。

新建自动房只能选择角色完成数为 `16/16` 且没有“待确认”规则的预组；当前已解锁【操作组】和【上头组】，可由两个账号分别选用进行交叉预组测试。自动模式不开放自选卡组，经典模式不受影响。完整进度见 [`auto-battle-character-status.md`](auto-battle-character-status.md)。修改角色时机或费用后运行：

```bash
npm run automation:sync
npm run validate
```

未实现角色的辅助结算层仍保留用于旧房间和开发过渡，但不会进入新建自动房的可选预组。

## 接口与部署

- 经典房：`/rooms/**`，页面 `/play/room`。
- 自动房：`/auto/rooms/**`，页面 `/play/auto/room`。
- 大厅摘要以 `mode: "classic" | "auto"` 区分模式；旧摘要缺少该字段时按经典房处理。
- 自动房由 `AutoBattleRoom` 保存，Cloudflare 迁移版本为 `v3`。

部署时先发布 Worker，再发布前端。完整本地检查：

```bash
npm run validate
npm run typecheck
npm run test:battle
npm run build:battle
npm run test:battle:auto:live
npm run test:battle:e2e
npm run build:web
```
