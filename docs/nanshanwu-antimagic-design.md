# 南山五：破魔流本体

## 范围与状态

- 正式名称为南山五，阿斯塔仅为外观与机制原型。稳定ID：`body_antimagic_001`。
- 正式技能以 `data/cards/bodies.json` 为唯一数据源；本轮写入本体、原画与卡面，不创建预组或在线技能模块。
- 7体力，强攻 / 反制 / 强化。正面特性【反魔法】，极巨化面【恶魔同化-南山五】，极巨技能【反魔法·恶魔同化】。

## 机制说明

对手角色技能结算后获得至多1枚反魔，使用【出刀】时消耗并增伤。每回合限一次限制获取，不能据此添加未确认的额外用刀次数限制；本体不额外授予用刀次数。

极巨化进度在移去反魔且强化成功时累计，阈值3。不检查出刀是否被闪避、防止或实际命中。极巨化沿用准备阶段激活、每局一次、3能量、2极巨体力及正面特性暂停的现有规则。

黑色分割强化下一张出刀，并阻止对手用角色能力挡刀，但仍允许手牌响应与本体特性。用户明确要求保留“受到伤害后”的角色技能，因此制卡文字写明该例外，不假定伤害后已等于整张牌结算完毕。反魔领域不继承该例外，只封锁选中的明置角色直到己方下个回合开始。

## 强度与待确认边界

- 反魔最多1枚限制储存量，但若本回合开始时已有反魔，又有额外用刀来源，则可能先消耗、再因对手技能结算获得、再使用；不能仅靠标记上限断言每回合最多强化一次。
- 普通形态依赖对手发动角色能力以及己方获得出刀，极巨形态封技不等于不可响应、必中或无视本体减伤。
- 后续需确认：技能被抵消是否计为“角色技能结算后”；满标记时是否消耗获取机会；变身前未使用反魔的保留方式。
- 后续需确认：极巨能量耗尽后已建立的延迟强化/封技如何与形态结束衔接；被反魔领域选中的角色离场重返或暗置后持续效果如何追踪。不能在实现时擅自扩大为同名角色永久封锁。
- 在这些边界与预组完成前，不开放自动对战使用。

## 原画与制卡

使用内置图片生成工具，每面独立生成，再按用户反馈分别柔化。参考项目 `xiaoapan-body.png` 的鹅脸、五指与比例，以及 `weixiao-body.png` 的平滑插画光影。保留黑色鹅身、灰白短发、头带、橙色嘴与蹼足，不改成人类。

- 正面提示要点：前倾蓄势，双手持巨大黑剑，剑刃左下至右上；局部反魔纹路而非完全恶魔化。小狗位于侧方，魔法阵被剑周围黑色能量瓦解。脸、持剑手与小狗面部置于卡面下部文字框以上。
- 背面提示要点：同一黑鹅高速俯冲斩击，角、双翼、反魔覆盖全面展开；小狗同步长出小角与暗翼。巨剑指向左下，远处建筑体现尺度，周围法阵破碎褪色。保持主体而非另添巨大灵体。
- 柔化提示要点：保留身份、动作和构图，减少密集裂纹及碎屑，降低写实皮毛与金属质感，采用平滑光影、清楚轮廓和较柔和的眼神高光；背面仍保留黑红压迫感。
- 本体源图：`src/assets/card-art-source/bodies/nanshanwu-body.png`。
- 极巨化源图：`src/assets/card-art-source/bodies/nanshanwu-body-dynamax.png`。
- 候选与前版：`/private/tmp/qunyou-character-art/body_antimagic_001/`。正式双面串行注册，不修改旧本体原画。

原型参考：[动画官方阿斯塔介绍](https://bclover.jp/season1/sp/character/character01.php)、[集英社角色介绍](https://www.shonenjump.com/j/sp_bclover/character/chara001.html)。反魔法与巨剑来源于角色设定；小狗及其恶魔化是用户指定的本项目视觉设计，不声称为原作设定。
